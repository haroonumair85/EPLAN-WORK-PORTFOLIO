Muhammad Umair Haroon - EPLAN portfolio website
================================================

Static site (index.html, cv.pdf, fonts/, img/). No build step.

Deploy on Vercel:

1. Push this repository to GitHub.
2. At https://vercel.com click Add New > Project and import the repository.
3. Framework Preset: Other. Leave Build Command empty. Output Directory: . (root).
4. Click Deploy. Every later push to main redeploys automatically.

Social preview: index.html points og:url and og:image at
https://eplan-work-portfolio.vercel.app/. If Vercel gives the project a
different domain, or you add a custom domain, update those two tags.
